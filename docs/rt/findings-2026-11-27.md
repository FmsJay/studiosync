# James's findings from his own tests (2026-11-27, StudioSync 0.60.1, extension 1.0.40)

Source: James, 2026-11-27, after testing on his own computers (not yet a full-band test). Agents: quote this file, don't paraphrase it
into your briefs. Model rule for now: Opus 5.5 and below; tell the orchestrator if something needs Fable.

## Big items
1. UI cleanup, moved entirely into the web view, with per-device awareness: it already knows whether this device has REAPER and, if so,
   what REAPER is doing / has open, so you only see what makes sense for your environment. Bring over the important, useful features from
   the panel and parts of its look, especially the button and strip, fullscreen, dock modes, minimizing when not in focus (or better
   behaviour for that if possible).
2. Screen share shows where the sharer's cursor is, plus "ask for control", and the modern capabilities of Discord / TeamViewer etc.
   (pop-out view, full screen, ...).
3. Besides "try" for VSTs: a way to simply add a bandmate's plug-in to the chain for processing, or combine the two, so borrowing someone's
   VST adds it to the track for real; you hear the processing and adjust as you go. Combines with the existing VST processing (the Hop),
   and missing packets wouldn't be an issue.
4. More controls/view when trying someone's VST or changing a VST setting on another machine: maybe screen share + control of that VST's
   window.
5. Following someone shows their REAPER view exactly (zoom, where they're looking/scrolling). Usable in the web view too, so anyone can
   follow along and see what everyone's view looks like. Much of this already exists.
6. AI tab: keep only stem separation and audio-to-MIDI for now.
7. History and Restore become one tab, with playback as a sub-tab.
8. Deleting the StudioSync Hop VST should be the same as stopping it.
9. Fold a person's computers together in a studio (James-Laptop and James-Main) so it isn't confusing for others.
10. Possibly no longer need dry and wet for everything now that plug-in hops and streams exist.
11. Sensibly rename tabs, controls and everything else to make more sense and be consistent.
12. Start together / Stop together / Record together should probably be replaced by "follow", to keep it simple; find a coherent, intuitive
    way of recording together in that mode.
13. Better project organisation, and better organisation/flow in general.
14. Avoid crashes when loading a project, especially big ones where someone clicks around early.
15. Keep making the web view's Project tab look, feel and edit exactly like the real project, with a toggle for actually editing there so
    nobody edits by accident.
16. Health: hide/show hidden items; hide/show other scripts' messages.
